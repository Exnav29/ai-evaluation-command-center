# Runtime Data

This directory may contain private evaluation evidence generated by the
AI Evaluation Command Center.

The public repository contains software, schemas, methodologies, rubrics,
skills, benchmark definitions, and synthetic demonstration data.

The following must never be committed:

- live evaluation databases
- raw run output
- private prompts or responses
- credentials or secrets
- unsanitized artifacts
- private stakeholder exports
- VPS-specific runtime information

See `examples/demo-data/` for safe synthetic demonstration datasets.
